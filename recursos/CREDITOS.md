## Cosas de afuera que se nombran (pero no se incluyen)

- **Paleta clásica de 28 colores** (`paint/paint.js`): son los valores de color del Paint de
  Windows 95/98. Son solo números de color (como `#808000`), no un archivo ni un dibujo: no tienen
  derechos de autor.
- **Letras de los stickers con texto** («¡Golazo!», «¡Che!», etc.): el SVG le pide al sistema
  *Arial Black* (o *Segoe UI Black* / *Impact* si no está). No se incluye ningún archivo de fuente:
  se usa la que ya trae la compu de cada uno, así que no hay nada que licenciar.

Si algún día se suma algo de afuera (un ícono, una fuente, un dibujo), anotalo acá con:
de dónde salió (link), quién lo hizo y qué licencia tiene.
